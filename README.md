## Workflow

For each problem:

1. Implement the solution in VS Code.
2. Test it locally with a typical test case and an edge case.
3. Verify the expected output.
4. Submit the verified solution on LeetCode.
5. Save the Accepted screenshot.
6. Document the approach and complexity.
7. Update the progress tracker.
8. Commit and push the work to GitHub.
